# Models and test data

The test signal is generated in each step's `main.cpp`, and the expected output
is compiled in (`steps/*/common/target_signal.h`, generated by
`tmp/make_test_data.py`), so only the model lives here.

In the repo, via Git LFS (65 MB):

- `forward_stateful.pt` — the model as TorchScript, for LibTorch. Audio in, audio out, 2048 samples per call, 48 kHz, one channel, state kept inside the model.

You need Git LFS to get the actual file:

```bash
git lfs install
git lfs pull
```

Without it the checkout contains a small text pointer instead, and the steps fail to load the model. To use a copy from somewhere else:

```bash
cmake -S . -B build -DWORKSHOP_MODEL=/path/to/forward_stateful.pt
```
